Errors at 1.8–2.0 s

Each value is measured over the 1.8–2.0 s window of every run (time since the run started), using only real vision samples, then averaged across trials: mean ± σ. The window is early enough that most X-ring runs, which lose camera tracking partway through, are still tracked, so configurations compare like for like. Trials with no vision sample in the window are left out, so check each cell's trial count: X-ring at 45° has only 3. Darker cells are larger errors. Also saved as window_errors.csv.
