Error summary

Variance and σ are across trials (of each trial's value) — how repeatable the result is. Runs with no vision data, or where the robot never moved (actual speed always below 0.05), are excluded. Also saved as rms_summary.csv.

Path shape (timing ignored)

Cross-track RMS: for every actual sample, the distance to the nearest point anywhere on the expected path — how far off the line the robot was, regardless of how late it got there. Final position / heading error: where the robot came to rest compared with the end of the expected path (heading as an absolute difference). Per-angle values: cross-track pools every sample; final errors are the mean across trials. Read cross-track together with final position error: a robot that barely moves stays near the start of the path, so it scores a low cross-track error but a large final error (e.g. 2540 at 90°/270°, where the robot mostly spins in place).
